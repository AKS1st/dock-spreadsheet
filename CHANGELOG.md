# Changelog

## 0.2.0

Read-only data-browser release: fix the misleading states and close the highest-value gaps found in the DSH native-preview comparison.

### Added

- **Formula bar**: the selected cell shows its actual formula; formulas without a cached result show `=formula` and a “no cache” badge instead of blank/zero.
- **Range selection and copy**: Tabulator `selectableRange` + `Ctrl/⌘+C` writes TSV and an HTML table to the clipboard. Toolbar actions: copy selection, copy the visible view, export CSV.
- **Structure metadata**: solid fills, source column widths, merged-range anchors (covered cells blank, range shown in the inspector), hidden rows/columns.
- **Hidden worksheets**: hidden/veryHidden sheets are hidden by default and can be revealed with a toggle that labels them.
- **Type-aware sorting**: numeric and date columns sort by value instead of by display string.
- **Refresh**: `↻` re-reads the same file; while open the viewer polls `POST /dock-spreadsheet/stat` (mtime/size) every 4 s and shows a “file changed” notice instead of silently keeping stale data.
- **Delimited-text robustness**: UTF-16 BOM decoding, GBK fallback when UTF-8 fails, and delimiter sniffing (`,`/`\t`/`;`/`|`).
- **Truncation detail**: the footer now shows the source total rows/columns alongside the 5000×256 preview limit.

### Fixed

- Dark mode no longer renders the viewer chrome and grid on a white background: four `--dsw-alias-*` tokens that do not exist in DSH 0.2.2-rc.1 were replaced with real theme tokens.
- No-cache formulas generated by openpyxl/XlsxWriter are no longer dropped from the grid.
- Re-opening or refreshing the same path now re-reads the file; previously the load effect only depended on the path.
- Missing/invalid sheets are caught by the view instead of failing during render.

### Changed

- Parsing now reads with `cellStyles`/`cellNF` and builds a typed cell model directly from `!data`; `sheet_to_json` is no longer the data path.
- Host adds `POST /dock-spreadsheet/stat` (same trusted-host/path/extension checks as `/read`).
- Test suite grew from 18 to 21 tests (formula/no-cache, hidden sheets, widths/merges, UTF-16/GBK/delimiter, stat route, and the updated React view checks).

### Not included yet

- Worker-based parsing/timeouts and cancellation.
- Native DSH integration (`remote.workspaceFiles` reads, `resources` version subscription for auto-refresh, `ctx.locale` i18n, `documentPreviews` “open in Harness” action).
- Exact merge-cell spanning, row heights, frozen panes, conditional formatting, fonts/borders/alignment (SheetJS CE cannot expose them).
- Multi-instance floating windows (requires a dock-base change).
